# Regulatory change control

A country module change is material when it alters scope, category, jurisdiction, registration/authority routing, reporting obligations or another decision outcome.

For a material change:

- cite the new official source;
- record source publication/effective date where known;
- record review date;
- update reason codes and unresolved validation items;
- add regression tests for changed paths;
- increment the relevant module/dataset version;
- document superseded sources where relevant.

Editorial, SEO or authority-directory changes must not alter legal verification status.

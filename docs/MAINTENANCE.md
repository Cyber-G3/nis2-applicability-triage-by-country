# Maintenance rule

For each national module review:

1. Review the applicable national legal instrument and official implementation guidance.
2. Record review date and source metadata.
3. Preserve previous decision semantics unless the source materially changed.
4. Add or update regression tests for affected paths.
5. Increment module/dataset version for material decision-logic changes.
6. Keep unresolved issues explicit in the exported decision record.
7. Never infer `verified` status from an authority directory or SEO page alone.

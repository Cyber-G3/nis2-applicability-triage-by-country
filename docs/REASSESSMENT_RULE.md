# Reassessment rule

A downstream applicability assessment should be flagged for reassessment when:

- the national module version changes materially;
- the module verification status changes;
- an official source is superseded;
- a relevant national law enters into force;
- authority/registration/jurisdiction routing changes;
- a previously unresolved validation item is resolved.

This allows legal-data changes to propagate through the broader GRC stack without silently changing historical decisions.

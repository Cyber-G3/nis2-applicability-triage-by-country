# Regulatory traceability

Every exported applicability decision should make it possible to answer:

- Which EU baseline logic version produced the decision?
- Which national module version/status was used?
- When was that national module last reviewed?
- Which official sources supported the result?
- Which assumptions or unresolved national-law questions remained open?
- Who reviewed/approved the assessment, if applicable?

Downstream GRC tools must retain these fields so a later legal update can identify which prior assessments may require reassessment.
